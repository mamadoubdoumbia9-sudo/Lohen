# Problèmes connus

1. Aucun JDK/Android SDK n'est installé dans l'environnement observé ; APK/AAB non produit.
2. Les polices distantes peuvent ne pas être disponibles hors connexion ; des fallbacks sont définis.
3. Le son est un retour minimal Web Audio, pas une bande originale.
4. Le jeu utilise des illustrations CSS plutôt que des fichiers image afin de rester léger et immédiatement vérifiable.
