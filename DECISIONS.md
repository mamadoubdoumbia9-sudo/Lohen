# Décisions de conception

- **Stack initiale :** HTML/CSS/JavaScript vanilla, car elle permet un jeu tactile immédiatement exécutable sans moteur et sans dépendance.
- **Direction :** illustration 2D CSS et typographie éditoriale, plutôt que personnages géométriques ou 3D placeholder.
- **Boucle :** observer → interpréter → résoudre → découvrir → avancer.
- **Sauvegarde :** `localStorage`, suffisante pour un parcours hors-ligne dans le navigateur.
- **Audio :** micro-signal Web Audio optionnel après geste utilisateur ; pas de musique sous licence tierce.
- **Android :** différé jusqu'à disponibilité d'un JDK/SDK vérifiable ; ne pas prétendre à un APK inexistant.
