# ASSET_MANIFEST — Pour Lohen

Every asset shipped in the APK, where it comes from and under which licence.
No third-party sample, stock image or scraped file is used anywhere: all the
art is generated for this project, all the audio is synthesised from scratch
with numpy, and the only external material is two open-source font families.

## 4. Voice-over (in the repository)

`android/assets/voice/letter_NN.flac` — Esteban's letter read aloud in French,
one lossless clip per paragraph, synthesised with the project's registered
narration voice. `LetterScreen` plays each clip as its paragraph appears and
waits for it to end before moving on; the text is identical to
`data/letter.json`, word for word.

## 5. Heavy tiers — generated on the CI runner, shipped in the Release APK

These are **not** committed: GitHub rejects files above 100 MB and the
workspace has its own size budget. They are produced by the
`Android Full Build` workflow and end up inside the published APK.

| Tier | Generator | Content |
|---|---|---|
| Cutscenes | `tools/gen_cutscenes.py` | 7 cutscenes, 1920×1080 JPEG frame sequences at 20 fps, real parallax (the illustration is split into depth slices), animated volumetric light, drifting particles, cross-dissolve to the next place, French captions. Streamed by `CutsceneScreen`. |
| HD soundtrack | `tools/gen_audio_hd.py` | 10 long-form cues (2–4 min each), 48 kHz / 24-bit stereo FLAC, lossless. One per chapter plus title, cutscene and letter cues. Each pass varies register, voicing and arpeggio density, so a cue is never a loop glued to itself. |
| HD art | `tools/gen_hd_art.py` | 2048 px lossless PNG masters of the backgrounds and of the letter paper, Lanczos upscale + unsharp mask. `Assets.tex()` picks them automatically, with a 2-texture LRU so memory stays flat. |

Everything in those tiers is derived from assets this project owns, and all of
it is actually used at runtime — nothing is padding.

## 6. What is *not* in the project

No stock photography, no asset-store package, no ripped sprite, no sampled
instrument, no third-party music, no font outside the two OFL families above.
